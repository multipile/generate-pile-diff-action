A GitHub Action that shows a pull request by pile and turns it into a prompt for an agent's review, and stops there: it reviews nothing itself.

What a user of the action sees belongs here: the inputs and outputs it promises, how to use it in a workflow, its releases, and the checks that run it as a user would. How `pile` reads a repository does not, nor what a review should find, nor a step of the action itself.

Read this pile to find out what the action takes, what it gives back, and how to use it in a workflow. Change it when the action gains or drops an input or an output, or a release changes which `pile` it installs by default.
